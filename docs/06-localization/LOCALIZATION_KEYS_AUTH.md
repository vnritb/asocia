# Nuevas claves de localización necesarias

## Para LoginView y SignupView

Añadir estas claves a tus archivos de localización (es.json, ca.json, en.json):

```json
{
  "signup.field.password": "Contraseña",
  "signup.field.confirmPassword": "Confirmar Contraseña",
  
  "login.title": "Iniciar Sesión",
  "login.email": "Email",
  "login.password": "Contraseña",
  "login.button": "Iniciar Sesión",
  "login.noAccount": "¿No tienes cuenta?",
  "login.createAccount": "Crear Cuenta",
  "login.error.invalidCredentials": "Email o contraseña incorrectos",
  "login.error.connection": "Error de conexión con el servidor"
}
```
